## 一、共享逻辑层（不属于任何页面，将来所有页面都调它）

这次只实现 1 和 4，2、3 写清楚规则等待点亮：

1. **规律引擎**（本次实现离线版）：喂 csv → 按 13 号文档的配方+门槛 → 出证据库 JSON。
   Demo 阶段用 Ginger 数据离线跑好，JSON 打进 App；正式版由艾瑞移植成 App 内引擎。
2. **引导收集服务**（本次只定规则）：引擎每条"数据不够"的菜，自动生成一条引导
   （"记满3次经期，我就能画你的周期地形"）。消费方：首页气泡（将来）、规律页"观察中"卡（本次）、
   AI 对话（艾瑞接）。气泡触发规则：一天最多 1 条；按"离门槛最近"排序（最快能给她惊喜的优先）；
   她无视 3 次就换一条，不重复纠缠（正反馈单向不对称的推论）。
3. **当下相关排序**：判断"她此刻处在哪条规律的窗口里"（经前X天/连睡第N天…），首页和规律页共用。
   本次静态版先写死一个"今天"的示例状态。
4. **文案五关质检**：所有上屏文案过 01-J 五关。本次由质检 Agent 人肉跑；将来是 prompt 链的一环。

## 二、页面总结构（从上到下）

```
规律页（tab 名建议从"洞察"改为"规律"，文案键改 JSON 即可）
├── ① 此刻卡（本页顶部，当下最相关的一条）      ← priority 排序的第一名
├── ② 我的规律（全部成立的规律，按 priority 从上往下，不设上限）
├── ③ 我的耗能预警（1张聚合卡）           ← 预警类规律的聚合视图
├── ④ 我的充能tips（1张聚合卡，杠杆律排序）← 可行动规律的聚合视图
├── ⑤ 我的能量故事（1张入口卡）           ← 走向全量身体故事页（本次只做入口+一屏摘要）
└── ⑥ 还在观察的线索（折叠区，默认收起）   ← 状态=观察中 + 引导收集
```

**今日页的唯一加法（只加不删，其余一切原样）**：
时间线里每条录音转文字条目，尾部加一个能量状态角标（五档：低/偏低/平稳/良好/充沛）。
Demo：TodayMockData 里每条假录音配一个写死的档位；档位样式=小圆点+一词文案（如"偏低"），
色值沿用页面现有色板。不做任何 AI 判断逻辑，不改时间线其他部分。

设计理由（给 Ginger）：你的四块全在（②③④⑤），加了两样——
"此刻卡"是杠杆律在页面上的形状（首屏只说今天最该知道的一条）；
"观察线索"是"敢说不知道"的展示位，也是引导收集的落点。
②③④可能引用同一条底层规律（经前既是规律也是预警），**页面上用"在预警里看它"跳转，不重复铺文案**。

## 三、每张卡的规格 + 文案初稿（Demo 用 Ginger 数据渲染；文案已对照 05 范本写，仍需质检过五关）

> 文案规则提醒：L1 零数字零术语；数字只活在下钻层；低谷必配伞；比喻必须当句自解释。

### ① 此刻卡
- 内容 = 距离最近的规律窗口。Demo 示例（假设"今天"距经前 3 天）：
  - **L1**："再过几天，你会进入这个月身体最费电的一周。提前把要紧的事挪一挪——不是你要变弱了，是身体要开始忙自己的事了。"
  - 下钻 → 跳到②里对应的经前规律卡
- IP：气象员萝卜在卡角播报（静态图，素材向小南要；没有就先用现有毛毡素材+文字角标）

### ② 我的规律（Demo 放 3 张成立规律）

**卡A · 经前那一周（周期相位配方）**
- L1："每次月经来之前的那一周，你都比平时更容易累——同样的事更耗电，恢复也更慢。这不是状态差，是你身体的固定节奏。而且这不怪你睡得晚：同样时间睡，充电效果照样打折。"
- L2（点开）："过去两年多，你的 22 个周期几乎每次都这样：睡眠修复、心跳回落、体温三个信号一起变差。差距大概是：平时的你 vs 连轴转了几天的你。"
- L3（再点开）：相位对比图 + 样本数（数字只在这层出现）
- L4："方向和已有研究一致。但这条是从你自己的日子里算出来的，只属于你。"
- 出口："这几天该怎么过 → 看③预警"

**卡B · 连着睡够三天，身体换挡（对比堆配方）**
- L1："只要连着三天睡够，你的身体就会从'欠债运转'切回'正常运转'——完全安静时的心跳明显慢下来，那是身体最省油的状态。这是你全部数据里，'做什么马上有用'最清楚的一条。"
- L2："三天是个坎：断断续续睡够不算，连着三天才触发。你有 79 天做到过——那些天你的待机油耗，和你状态最好的日子一个水平。"
- L3：对比柱状图 + 数字
- 出口："它也是充能tips第一名 → 看④"

**卡C · 晚睡是慢坡，不是悬崖（剂量梯度配方）**
- L1："晚睡对你不是'过了12点就完蛋'，是每晚一点、多扣一点电。真正的悬崖在三点：过了三点才睡，睡够的机会直接掉一半——因为你早上醒来的时间是固定的，晚睡的债躲不掉。"
- L2："别因为已经一点了就破罐破摔——这个点睡下，你多半还能睡够；拖到三点后，十次里只有三次能睡够。"
- L3：台阶图 + 数字
- 出口：无（认识型规律，安静躺着）

### ③ 我的耗能预警（聚合卡）
- L1 标题："你最容易被掏空的时候"
- 内容三行（每行可点进对应规律）：
  - "月经前那一周（下次：X月X日前后）" → 卡A
  - "连续没睡够的第二天起" → 卡B 反面
  - "身体打仗的日子——腕温、呼吸、心跳一起偏高时，我会在当天告诉你" → E1 哨兵说明
- 每行右侧配伞角标：点开是"这种时候怎么过"一句话（"安排轻一点，是聪明不是偷懒"）
- IP：哨兵萝卜站岗

### ④ 我的充能tips（聚合卡，杠杆律排序）
- L1 标题："对你最划算的充电方式"
- 第1名（大字）："连着三天睡够。不用早睡，先求'连着'——三天就能看见身体换挡。"
- 第2名（小字）："白天晒到太阳的日子，你晚上通常睡得更多。这条还在攒证据，但它几乎零成本。"
- 尾行（诚实边界）："多走路对你的恢复有没有帮助？看不出来。数据不撒谎，我们也不硬凑。"
- IP：园丁萝卜递水壶

### ⑤ 我的能量故事（入口卡）
- L1："你的一天有自己的地形：上午是省电的深水区，适合啃硬骨头；下午身体一直踩着小油门，适合见人、动手、跑杂事。"
- 下钻：一屏日内曲线图（hourly 数据画）+ "完整故事以后住在这里"的占位
- 注：这条和地图页有重叠——**本次只做卡+一屏，地图页一根线都不碰**，将来两处合并由艾瑞定

### ⑥ 还在观察的线索（折叠区）
- 标题："我还在琢磨的（还不算数）"
- Demo 两条：
  - "你的周三常常是一周里最蔫的一天——睡最少、动最少。我猜和周二晚上的安排有关，但还没对上。哪天你愿意，跟我说说你的周二晚上。"（引导收集）
  - "戴耳机特别久的日子，你睡得也特别晚。是刷着东西睡不着，还是睡不着才刷？我分不清方向，需要多认识你一阵子。"
- 设计理由：敢说不知道 + 每条都带一个"你能帮上忙"的口子，这就是气泡逻辑在本页的形态
