# METRIC-RESP · 睡眠呼吸频率

## 1. 生理机制

呼吸频率由脑干呼吸中枢自动调控，主要响应血液 CO2 分压（其次是 O2 与 pH）。睡眠中代谢率下降、行为性干扰消失，呼吸频率进入个体相对固定的低位区间（成人常见约 12–20 次/分），且**个体内夜间基线非常稳定**——这正是它作为监测指标的价值：数值本身信息量低，"偏离自己的基线"才有信息。影响它的系统性因素包括：代谢率/体温（发热时通气需求上升）、化学感受器敏感度（孕酮等激素可上调）、呼吸道阻力、以及中枢抑制（酒精、镇静类物质）。

## 2. 已知影响因素

| 因素 | 方向 | 优先级 | 出处 |
|---|---|---|---|
| 呼吸道感染/发热（感冒、流感、COVID 等） | 可穿戴生理指标异常可早于呼吸道症状出现（心率/活动证据为主，呼吸频率特异性证据待补） | P2 | Temple 2023 (PMID 35759279，ECG+活动信号)；Alavi 2022 (PMID 34845389，心率+步数)——两文支持"可穿戴信号异常早于症状"，非呼吸频率特异性证据 |
| 饮酒（尤其睡前） | 多为升高（伴心率升高、HRV 下降）；大量饮酒也可能抑制呼吸 | P1 | 佩戴设备厂商与睡眠生理综述；未能在线核实单篇 |
| 海拔/旅行到高原 | 升高（低氧驱动通气增强） | P2 | 经典高原生理学；未能在线核实单篇 |
| 月经周期（黄体期孕酮升高） | 可能小幅升高通气驱动；夜间呼吸频率变化幅度小、个体差异大 | P2 | 孕酮-通气经典文献（Behan 等）；未能在线核实 |
| 睡前剧烈运动、高温环境 | 轻度升高 | P3 | 一般运动生理；未能在线核实 |
| 镇静类药物 | 降低 | P3 | 药理学常识；涉及用药一律不做个体解读 |

## 3. analysis_hypotheses（核心节）

### H1 个人基线高度稳定，偏离才是信号 · P1
- 陈述：同一用户的夜间呼吸频率中位数在数周尺度上波动很小（多数人日间差 <1–2 次/分）；因此分析单位应是"相对基线的偏差（z 分数或次/分差值）"，而非绝对值。
- 方向：先验假设，作为其他所有假设的前置校准步骤。
- 数据字段：HKQuantityTypeIdentifierRespiratoryRate（按夜聚合中位数）+ 佩戴时长。
- 最少样本：≥14 个有效夜建立基线（滚动 28 夜更稳）。
- 出处：睡眠期呼吸监测可靠性研究（Ravindran 2024, PMID 39190477 ✅，为非腕戴设备，方法学参考）；WHOOP/Oura 白皮书口径未能在线核实。

### H2 疾病来临前的可穿戴生理指标异常（含呼吸频率） · P2
- 陈述：呼吸道感染发病前 1–3 天，可穿戴生理指标异常可早于呼吸道症状出现（心率/活动证据为主，呼吸频率特异性证据待补）；夜间呼吸频率相对基线升高 ≥1.5–2 次/分且持续 ≥2 夜、并伴静息心率升高/HRV 下降时，值得提示用户"注意休息、观察症状"。
- 方向：呼吸频率偏差 → 随后数日出现主观"生病/喉咙痛/疲惫"记录（前瞻关联）。
- 数据字段：RespiratoryRate 夜间偏差 + HeartRate（睡眠静息）+ HRV(SDNN) + 主观症状标签。
- 最少样本：≥1 次有记录的患病事件 + ≥28 夜基线；跨事件验证需 ≥3 次。
- 出处：Temple 2023, J Infect Dis (PMID 35759279) ✅（ECG+活动信号）；Alavi 2022, Nat Med (PMID 34845389) ✅（心率+步数）——两文支持"可穿戴信号异常早于症状"；呼吸频率特异性证据仅可能来自 Chen 2024, Digit Health (PMID 39465220) ✅，待补充呼吸频率专门文献。

### H3 呼吸频率偏高的夜晚，睡眠质量更差 · P2
- 陈述：相对基线偏高的夜（如 +1 次/分以上）与深睡比例下降、夜醒增多、主观睡眠评分更低相关（共同上游常是饮酒、发热、压力）。
- 方向：同夜相关，不设因果方向；作为"今晚身体负荷偏高"的汇总证据之一。
- 数据字段：RespiratoryRate 偏差 + HKCategoryTypeIdentifierSleepAnalysis（深睡/REM/清醒时长）+ 主观睡眠评分。
- 最少样本：≥30 个有效夜且含 ≥5 个偏高夜。
- 出处：机制合理性推断 + 佩戴设备研究间接支持（Berryhill 2020, PMID 32043961 ✅ 为睡眠测量效度背景）；直接证据未能在线核实。

### H4 饮酒夜的呼吸频率升高 · P2
- 陈述：有饮酒标签的夜，呼吸频率相对基线升高，且升幅可能与酒量正相关。
- 方向：饮酒（当晚）→ 夜间呼吸频率偏差。
- 数据字段：RespiratoryRate 偏差 + 主观记录"饮酒/杯数"标签。
- 最少样本：≥5 个饮酒夜 vs ≥20 个非饮酒夜。
- 出处：未能在线核实单篇（本次检索被安全过滤拦截）；以用户自身 A/B 数据验证为主。

### H5 黄体期呼吸频率小幅升高 · P3
- 陈述：黄体期（排卵后至月经前）夜间呼吸频率可能较卵泡期小幅升高（预期 <1 次/分），与孕酮的呼吸驱动作用一致；效应小，需较长数据才能分辨。
- 方向：周期相位 → 呼吸频率偏差（与体温、静息心率的黄体期上升趋势并行验证）。
- 数据字段：RespiratoryRate 偏差 + 月经记录（HKCategoryTypeIdentifierMenstrualFlow）+ 腕温/静息心率。
- 最少样本：≥3 个完整周期。
- 出处：孕酮-通气经典生理文献；本次未能在线核实，标记待核。

## 4. Confounds（混杂因素）

- **感染、饮酒、压力同向共变**：三者都推高呼吸频率并压低睡眠质量，H2/H3/H4 互为混杂，解读时需交叉核对当晚标签。
- **周期相位 vs 生病**：黄体期本身伴体温/心率/呼吸小幅上升，勿把周期性波动误报为"生病前兆"（建议按相位分别建基线）。
- **睡姿与伴侣干扰**：侧卧/仰卧、同床者活动可能影响传感器估计。
- **环境**：卧室高温、空调、鼻塞过敏季节都会独立影响呼吸。
- **海拔/旅行**：旅行夜应打标签并暂缓与基线比较。

## 5. 数据质量注意

- **仅睡眠时段有值**：需佩戴 Apple Watch 入睡并开启睡眠专注/睡眠追踪；未佩戴夜为缺失，不是"正常"。
- **依赖佩戴质量**：表带过松、电量不足中断、白天补觉时段都会造成缺测或噪声；建议有效夜定义为"睡眠时长 ≥3h 且有呼吸频率样本"。
- **粒度**：HealthKit 中通常为睡眠期间的间隔样本，建议取**夜间中位数**做日级指标，均值易被短暂伪影拉偏。
- **精度**：腕戴推算与医疗监测存在差异，±1 次/分内的波动不应解读。
- **软件版本/机型差异**：换表、系统大版本更新后建议重建基线。
