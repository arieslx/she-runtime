# 指标知识卡规范 v1（1a 交付物）

> 兼容艾瑞知识库 schema（https://arieslx.github.io/2026/08/26/body-knowledge-papers/），
> 扩展 3 字段：analysis_hypotheses / confounds / metric_bindings。
> 硬规则（沿用艾瑞）：avoid_claims 必填——没有禁用措辞的内容不进库；引用须真实可查（PMID/DOI/URL）。

## 卡片结构（YAML frontmatter + 正文）

```yaml
---
card_id: METRIC-XXX
metric_zh: 指标中文名
metric_bindings: [HKQuantityTypeIdentifier...]   # 对应 HealthKit 标识符
what_it_is: 一句话它测什么
what_it_is_not: 一句话常见误解（如 HRV≠压力值）
internal_priority_note: 本卡各假设按 P1(系统综述/荟萃) P2(叙述综述/观察/单RCT) P3(小样本) 标注
safe_claim_style: 本指标反馈的示范措辞（"可能同时出现，值得观察"式）
avoid_claims:
  - 禁用措辞1
  - 禁用措辞2
last_reviewed: 2026-08-28
---
```

正文五节：
1. **生理机制**（≤5 行人话）
2. **已知影响因素**（清单，每条标 P1/P2/P3 + 出处）
3. **analysis_hypotheses 可检验假设清单**（挖掘端核心。每条：假设陈述 / 预期方向 / 需要的数据字段 / 最少样本量建议 / 出处+优先级）
4. **confounds 混杂坑清单**（分析时"别上当"：环境/行为/设备因素）
5. **数据质量注意**（Apple 设备的采样方式、缺失模式、已知偏差）
6. **参考文献**（编号列表，PMID/DOI/URL，标注哪些经 Agent 在线核实、哪些凭训练知识待核）
